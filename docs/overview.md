# Capell Extension Cookbook

<!-- prettier-ignore-start -->

## What it does

Extension Cookbook is a free example package that developers use to learn how
to extend Capell. It adds small, working examples rather than an editing workflow.

## Do I need to do anything?

No action is needed for normal site editing. You can uninstall it on a production
site if you do not use its example content or widgets.

## Where it shows up

Under **System**, you may see **Capell Extension Cookbook** and **Reference entries**.
It also adds example dashboard cards and a **Capell Extension Cookbook widget**
in Layout Builder. These examples can be left unused.
