Developers building their first Capell extension can read and copy from a small one that already works. A site owner gets nothing from it and can leave it out.

Under Developer in the admin, Capell Extension Cookbook adds a coverage list. It marks the main ways a developer plugs into Capell as Demonstrated, or as Deliberately inactive where the sample leaves one switched off. Next to it sits a made-up list of Reference entries, and setting the package up for a site adds one example entry there.

Installing it also adds a public page at /extension-cookbook, where any visitor sees the titles of the enabled entries. Remove it before launch if you only needed it for learning. It needs the admin, the website and Layout Builder installed first.

A sample widget shows a title and a summary as a card, and a small health check and a doctor command come with it.
